Politique de confidentialité

Mise à jour : 17 octobre 2026

En bref : aucun compte n’est requis. L’application ne transmet pas votre progression ni vos préférences à un serveur Formation Civique. Certaines fonctions du système, les liens externes et Expo Go ont leurs propres échanges de données techniques, décrits ci-dessous.

1. Qui est concerné ?

Cette politique concerne l’application Formation Civique et sa version web lorsqu’elle est publiée. Formation Civique est un outil éducatif indépendant, non un service officiel du gouvernement français. Pour une question relative à cette politique, contactez le mainteneur via les issues du dépôt GitHub.

2. Données enregistrées dans l’application

L’application peut enregistrer sur l’appareil ou dans le navigateur les informations nécessaires à son fonctionnement :

  • nom ou pseudonyme et avatar, s’ils sont renseignés ;
  • préférences d’apparence, de taille du texte, de parcours et de quiz ;
  • progression des leçons, réponses et progression des quiz, historique, favoris et questions à réviser ;
  • objectifs quotidiens, plan d’étude du jour, temps d’étude, séries et badges ;
  • préférences audio et rappels programmés.

Sur Android et iOS, les données sont conservées dans le stockage local de l’application. Certaines valeurs sensibles peuvent utiliser le stockage sécurisé fourni par le système. Dans un navigateur, le stockage local du navigateur est utilisé.

3. Transmission, compte et suivi

L’application ne comporte pas de création de compte ni de service Formation Civique qui collecte ou synchronise la progression et les préférences. Elle n’intègre pas de publicité, de suivi publicitaire ou d’outil d’analyse d’utilisation.

Les builds natifs utilisent les polices d’icônes intégrées au projet. Expo Go peut télécharger ces polices depuis le CDN jsDelivr ; ce fournisseur reçoit les informations techniques habituelles liées à une requête réseau, comme l’adresse IP. Ce chargement est propre à Expo Go, pas aux builds natifs de test ou de production.

Si vous choisissez « Rechercher une mise à jour » dans les paramètres, l’application interroge l’API publique des releases GitHub de Formation Civique pour repérer un nouvel APK. GitHub reçoit les informations techniques habituelles de cette requête, notamment l’adresse IP. L’APK n’est téléchargé qu’après votre choix et l’application ne l’installe pas automatiquement. Le signalement d’un problème ouvre un e-mail prérempli ; aucun message ni donnée de diagnostic n’est envoyé tant que vous ne décidez pas de l’envoyer depuis votre messagerie.

4. Rappels et autorisations

Les rappels d’entraînement sont facultatifs. Après votre autorisation, le système d’exploitation programme et affiche les notifications sur l’appareil. L’application n’envoie pas ces rappels depuis un serveur. Vous pouvez modifier ou annuler les rappels depuis les paramètres de l’application ou les réglages de notification du téléphone.

5. Audio et synthèse vocale

Les enregistrements de leçons inclus dans l’application sont lus localement. La synthèse vocale utilise le moteur et les voix configurés sur votre appareil. L’installation ou le téléchargement de données vocales relève du fabricant ou du fournisseur du système et peut nécessiter une connexion Internet. Android peut afficher des commandes multimédia locales pour les enregistrements inclus.

6. Liens, partage et sauvegarde

Les liens vers des sites tiers s’ouvrent dans le navigateur ou l’application choisie. Ces services appliquent leurs propres politiques de confidentialité.

Lorsque vous demandez un export, l’application prépare un fichier JSON avec des préférences et données de progression. Si vous choisissez ensuite de le partager ou de l’enregistrer dans un service, ce destinataire reçoit le fichier selon votre choix et ses propres conditions. L’import lit le fichier choisi et écrit les valeurs reconnues dans le stockage local.

Le système d’exploitation peut inclure les données d’application dans une sauvegarde de l’appareil si vous avez activé cette fonction dans ses réglages. Ces sauvegardes sont gérées par la plateforme, pas par un serveur Formation Civique.

7. Conservation et suppression

Les données restent dans le stockage local jusqu’à leur suppression. Dans les paramètres, vous pouvez réinitialiser la progression des leçons, l’historique des quiz, les révisions et favoris, ou toutes les données locales. La désinstallation supprime les données locales de l’application ; une sauvegarde système peut en conserver une copie selon les réglages de l’appareil.

8. Version web

La version web conserve les données dans le stockage du navigateur sur l’appareil. Effacer les données du site dans le navigateur les supprime. Les rappels locaux natifs et certaines fonctions du lecteur audio peuvent ne pas être disponibles sur le web.

9. Modifications de cette politique

Cette page peut être mise à jour si le fonctionnement de l’application change. La date en haut de la page indique la dernière mise à jour publiée. Les versions récentes du texte sont également consultables dans le dépôt du projet.
